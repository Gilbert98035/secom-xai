# SECOM 半導體測試未通過預測與 SHAP 解釋

用半導體製程的歷史量測預測測試結果，並以 SHAP 拆解正確告警、誤報和漏報。依時間切分資料，模擬用過去資料訓練，再評估較晚的樣本。

**回測結果**　測試期有 24 筆未通過，模型抓到 1 筆、漏掉 23 筆，另有 45 筆誤報。測試平均精確率（AP）為 0.0575，低於常數基準 0.0599。SHAP 個案顯示，正確告警和一筆誤報獲得相同分數。這次回測的表現不足以支持將模型用於預警。

- [SECOM_XAI.ipynb](SECOM_XAI.ipynb) 提供六個已執行的程式區塊與六張圖。
- [SECOM_XAI.py](SECOM_XAI.py) 提供對應的 Python 程式，可從頭到尾執行。
- [requirements.txt](requirements.txt) 列出已用於重現結果的核心套件版本。

## 1. 資料稽核
原始 CSV 有 1,567 筆、590 個量測欄位和 104 筆未通過（6.64%）。全檔有 41,951 個量測缺值，28 欄缺值超過半數，116 欄有效值只有一種。完整列沒有完全重複。這些全檔統計用於描述資料，模型欄位篩選另以訓練集計算。

## 2. 時間修正與切分
CSV 有部分月日對調。先假設列序符合時間非遞減，針對每列比較正常和互換兩種日期，再從頭、從尾各推一次。兩個方向都得到相同結果，共修正 582 筆。調整後的範圍是 2008-07-19 至 2008-10-17。這個解在列序假設下唯一。

| 用途 | 時間範圍 | 總筆數 | 未通過 |
|---|---|---:|---:|
| 訓練 | 9 月 1 日前 | 618 | 65 |
| 驗證 | 9 月 1 日至 9 月 28 日 | 548 | 15 |
| 測試 | 9 月 29 日起 | 401 | 24 |

## 3. 前處理與模型選擇
用訓練資料移除缺值過半和有效值至多一種的欄位，剩 444 欄。缺值以訓練中位數補齊。邏輯迴歸另外做標準化。常數基準代表無法區分高低風險的排序表現。

| 候選模型 | 驗證 AP |
|---|---:|
| 深度 3 決策樹 | 0.0504 |
| 深度 2 決策樹 | 0.0485 |
| 邏輯迴歸 C=0.01 | 0.0346 |
| 邏輯迴歸 C=0.1 | 0.0306 |
| 常數基準 | 0.0274 |

## 4. 歷史回測
依驗證 AP 選深度 3 決策樹。測試 AP 為 0.0575，常數基準為 0.0599。用驗證誤報率上限 10% 選出主門檻 0.5864，驗證誤報率為 7.32%。相同門檻套用到測試期後，401 筆中有 46 筆被標為高風險，其中只有 1 筆真的未通過。23 筆未通過被漏掉，377 筆通過當中有 45 筆誤報（11.94%），召回率為 4.17%。這次回測未建立模型可用於預警的證據。5%、10% 和 20% 是用來比較門檻的示例。

## 5. SHAP 結果
以 64 筆訓練樣本為背景，枚舉決策樹實際使用的欄位組合，計算相對於背景平均分數的精確介入式 SHAP 值。401 筆解釋都通過加總檢查。全體平均絕對貢獻最大的三個欄位是 59、144、41。

- **抓到的案例**（CSV 第 1445 列，從包含標頭的第 1 列計數）與**誤報案例**（第 1203 列）得到同樣的 0.5864 分數與 SHAP 貢獻。兩筆的欄位 41 都把分數推高約 0.3424，欄位 144 都把分數拉低約 0.1456。模型做出相同判斷，但實際結果不同。
- **漏報案例**（第 1187 列）的分數為 0.0885。欄位 144、59、41 的貢獻都往下降，其中欄位 144 的負向貢獻最大。

欄位是匿名編號。SHAP 描述這個模型如何得分。要追查製程原因、確認量測是否早於測試，還需要欄位定義與量測取得時間。

## 重跑專案

1. 從下方 Kaggle 資料頁下載並解壓縮，將 `uci-secom.csv` 放在與 `SECOM_XAI.py` 相同的專案根目錄。保留原始列序，日期修正會用到它。
2. 在專案根目錄用 Python 3.13 建立環境並安裝套件。這是本次驗證使用的 Python 版本。

   ```bash
   python3.13 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   python SECOM_XAI.py
   ```

   Windows PowerShell 使用 `.venv\Scripts\Activate.ps1` 啟用環境。

3. 若要逐步執行 Notebook，可在同一個環境選擇性安裝 JupyterLab。

   ```bash
   python -m pip install jupyterlab
   python -m jupyter lab SECOM_XAI.ipynb
   ```

SHAP 計算已寫在程式中。整個分析可在本機執行，所需資料是下載後的 CSV。
